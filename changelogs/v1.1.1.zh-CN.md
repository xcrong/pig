# pig v1.1.1（2026-10-01）

一句话亮点：Windows 发版回归，附带一整批 Windows 构建兼容修复。

## 修复

- 清零 Windows 下 `cargo check` 报出的 9 处警告：`clipboard` 的跨平台导入按 Linux 门控、arboard 错误透传重构掉多余的初始赋值、`terminal` / `probe` / `workspace_server` / `shell-terminal` 按平台收敛未使用参数、导入与函数。
- `protoc` 调用改用临时文件，摆脱对 `/dev/null` 与 `/dev/stdout` 的 Unix 假设，Windows 上也能正常生成。
- Windows 目标加上主线程栈保留（MSVC `/STACK:16MiB`、gnu `--stack`），缓解深递归场景的栈溢出。
- 平台相关测试与示例加上 `cfg` 门控：在 Windows 上跳过符号链接种植用例、argv 形态检查与 sandbox 烟雾测试，无需特权或开发者模式即可跑通测试。
- `HeldDir::replace` 改用 rename 语义写入，链接位置由重命名替换而不是写穿。

## 构建与发布

- 发版矩阵加回 `windows-2025`，产物为 `pig-windows-x86_64.tar.gz`：protoc 改走 choco 安装，ripgrep 预取支持 msvc triple 并兼容 `rg.exe` 文件名，打包步骤区分 `pig.exe` 与 `pig`。
- 发版目标恢复为三平台：linux x64、mac arm64、windows x64。

## 其他

- `Cargo.lock`：`find-msvc-tools` 由 0.1.13 升级到 0.1.14，解开它与 `cc` 1.2.48 的不兼容，这也是 Windows 发版曾经下线的原因。
