# pig v1.0.1 (2026-09-28)

First independent-version release: pig no longer tracks upstream version numbers and increments on its own baseline instead. Content-wise: vendor models gain reasoning effort levels and distinguishable names, vendors become explicitly opt-in, plus a context window config fix.

## New features

- Reasoning effort levels for vendor models: the effort menu is derived from snapshot data following pi's rules, so `/effort` and `/model <model> <level>` work on vendor models with no hand-written config; new upstream levels are picked up automatically.
- Vendors are now explicitly opt-in: a vendor catalog loads only with `[vendors.<id>] enabled = true`; credentials are read solely from the configured `env_key` / `api_key`, and enabling without a credential warns (running credential-less BYOK is a conscious choice). `--config` patches and campaign remote patches cannot enable these sources.
  - ⚠️ Behavior change: if you relied on vendor models loading by default, enable them explicitly in `config.toml`, e.g.:
    ```toml
    [vendors.opencode-go]
    enabled = true
    env_key = "OPENCODE_API_KEY"
    ```

## Fixes

- Fixed an explicitly configured `context_window` equal to the default value (256000) being overwritten by the same-slug vendor entry; any value written in `[model.*]` now always takes effect.

## Branding & UI

- Vendor model names carry the catalog key suffix by default (`Name (vendor/id)`), so the `/model` picker, settings panel, and status line stay distinguishable everywhere; what you see is what you can submit.
- The status line, empty-state composer, and welcome page show only the short model name for a cleaner UI; the full name remains in the picker, settings, and anywhere disambiguation matters.

## Build & release

- Independent versioning: pig no longer tracks upstream version numbers; a `v*` tag cuts a release (`Cargo.toml` version, tag suffix, and log filenames stay consistent). Re-align with upstream later via a whole bump when needed. The old `pig-v*` naming is retired; historic tags and logs are left untouched.

## Others

- Vendor snapshots synced to the upstream 2026-09-28 catalog: 76 opencode models, 29 opencode-go models; adds `longcat-2.5-preview-free`; opencode-go retires 4 models including `kimi-k2.6` and `glm-5.1` (still available on the opencode side).
- Upstream baseline: monorepo `036a5d8` (version 1.0.41); no upstream sync in this release.
